# 📚 Library Management System

A desktop-based Library Management System developed using **Core Java and Java Swing**.

The application provides a simple and classic library interface for managing books, members, and book transactions.

## ✨ Features

- 📊 Dashboard
- 📚 Book Management
- 👥 Member Management
- 🔄 Issue & Return Books
- 🔎 Book Search
- 📋 Book and Member Lists
- 🖥️ Desktop GUI using Java Swing
- 🎨 Classic Library-style UI

## 🛠️ Technologies Used

- Java
- Java Swing
- OOP
- ArrayList
- JTable
- IntelliJ IDEA
- Git & GitHub
